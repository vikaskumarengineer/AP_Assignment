**Question:** Write a C program for three different operations as stated in question 1 to analyze the space complexity.

## Solution Overview
This program demonstrates three types of space complexities:
- **O(1) - Constant Space**: Memory usage doesn't change with input size
- **O(n) - Linear Space**: Memory usage increases linearly with input size
- **O(n^2) - Quadratic Space**: Memory usage increases quadratically with input size
